NeckCare Web App

เปิด index.html ผ่าน HTTPS (เช่น GitHub Pages/Netlify) เพื่อให้ Safari บน iPad ขอสิทธิ์กล้องได้
ระบบ: ชื่อ/เลขที่/คะแนน 0-25 -> แบ่งระดับ -> ท่าผ่อนคลาย 3 ท่า -> จับเวลาท่าละ 1 นาที -> กล้อง -> สรุปผล
หมายเหตุ: เป็นเว็บแอปต้นแบบเพื่อส่งเสริมสุขภาพ ไม่ใช่เครื่องมือวินิจฉัยโรค และการบันทึกวิดีโอจริงควรมีการขอความยินยอมและกำหนดการเก็บข้อมูลให้ชัดเจน
